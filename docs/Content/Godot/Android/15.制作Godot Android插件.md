### 创建插件
1. 新建Godot工程,安装Android模板,在工程目录下(/android/build/libs/debug or release)中找到godot-lib.debug.aar和godot-lib.release.aar
2. 新建Android工程,导入(右键项目New/Android Module)上步骤的两个aar(新版本Android Studio不支持该功能,需要老版本 4.2?)
3. 在Android工程中新建Android Module/Android Library,对该Library按下F4.即属性配置,在配置选项中选择Dependencies,按加号导入Module Dependence(上步骤的两个arr),如果项目没刷新,可以手动导入(在新建Library下编辑build.gradle, 编辑其Dependencies:
	1. 删除Dependencies所有内容,并删除Library下的/src/androidTest and test)
	2. 写入
	``` js
	dependencies {
		debugCompileOnly project(':godot-lib.debug')
		releaseCompileOnly project(':godot-lib.release')
	}
	```
	3. 在Library的AndroidManifest.xml添加:
``` js
//android:name为包名,android:value为Library中主类的引用名
<application>
	<meta-data
		android:name="org.godotengine.plugin.v1.ToastPlugin"
		android:value="mobi.vhly.godotplugins.toastplugin.ToastPlugin"/>
</application>
```
4. 编写主类代码, 然后编译(点击Gradle图标输入build)
``` java
package mobi.vhly.godot.toastplugin;

import org.godotengine.godot.plugin.GodotPlugin;

pubilc class ToastPlugin extends GodotPlugin{

	public ToastPlugin(Godot godot){
		super(godot)
		// TODO: 可以获取 Activity
	}

	//返回值和清单内容一致
	@Override
	public String getPluginName(){
		return "ToastPlugin"
	}

	//坑点:所有需要在Godot脚本中调用的方法,必须是@UsedByGodoot
	//或者通过废弃方法getPluginMethods
	@UsedByGodot
	public void showToast(String msg){
		//TODO: 显示Toast
		//坑点 Godot调用 Android 方法,需要强制进行主线程/UI线程调用
		Activity activity = getActivity();
		if(activity != null){
			activity.runOnUiThread()->{
				Toast.makeText(activity,msg,Toast.LENGTH_SHORT).show()
			
			//发生信号，注意：需要注册信号后才能发送
			//比如下面的参数 3 会由int.class封包为一个Integer.class
			emitSignal('on_toast_shown',3)
			}
		}
	}
	
	//注册信号
	@Override
	public Set<SignalInfo> getPluginsSignals(){
		HashSet<SignalInfo> infos = new HashSet<>();
		//坑点:Java高版本会对基本类型进行强制封包成对象
		//传入的基本类型参数被封包
		infos.add(new SiganlInfo("on_toast_shown",Integer.class))
		
		return infos;
	}
}
```
5. 在Godot工程的android/plugins目录下新建 ToastPlugin.gdap文件(文件名和清单保持一致), 并导入编译好的aar文件于同目录. gdap格式如下
``` js
[config]

name="ToastPlugin"
binary_type="local"
binary="ToastPlugin.aar"

```
6. 导出设置中勾选该插件
7. Godot脚本调用插件函数:
``` js
if Engine.has_singleton("ToastPlugin"):
	var singleton = Engine.get_singleton("ToastPlugin")
	//绑定插件的信号
	singleton.Connect("on_toast_shown",this,nameof(on_toast_showed))
    print(singleton.showToast("Hello World"))

func on_toast_showed(){
	pass
}
```
