>[Advanced Godot | Showing Local Android Notifications With Godot 3.2 - YouTube](https://www.youtube.com/watch?v=dL4sEMnvgsc)

1. 安装Android构建模板
2. 安装Godot插件NativeLib
3. 使用插件NativeLib安装LocalNotification(或者手动安装,安装NativeLib后从C:/Users/Mosiv/.nativelib/meta中文本链接下载,解压扔进项目下Android文件夹)
4. 导出设置中勾选该插件LocalNotification
5. 代码调用:
``` js
if Engine.has_singleton("LocalNotification"):
	var ln = Engine.get_singleton("LocalNotification")
	//参数依次为 标题 内容 持续时间
	ln.showLocalNotification("title","content",2,1)
```
