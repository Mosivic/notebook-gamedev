### 保存与加载数据文件 
godot默认的用户数据文件位置(可以在项目设置中 **Config/Use Custom User Dir** 更改)：

![[00.jpg]]

脚本里可以通过 **user://** 访问到

**dat文件保存与加载数据**

``` python
#检测文件存在
var save_path = "user://data.dat"

var dir = Directory.new()
if not dir.dir_exists(save_path)
    dir.make_dir_recursive(save_path)

#保存
var file = File.new()
var state = file.open(save_path, File.WRITE)  #如果需要加密功能，使用 file.open_encrypted_with_pass() ,第三个参数为加密密码
if state == OK:
    file.store_var(data) #data数据建议用字典
    file.close()

#加载
var file = File.new()
var state = file.open(save_path, File, File.READ) 
if state == OK:
    var data = file.get_var()
    file.close()
```
