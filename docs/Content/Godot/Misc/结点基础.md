####  PS：增加高亮功能 ####

TextEdit自带语法高亮，在Dock栏打开该选项即可，默认的高亮也可以在选项中指定或更改颜色

如果要另外指定语法高亮，可以使用代码添加：

```python
add_keyword_color("Hello",Color()) #给特定Sting指定颜色,Hello
add_color_region('""','""',Color()) #指定区域颜色，" "
```

### MenuButton 结点 ###

#### 菜单用，展开可选择子项 #### 

可以直接从场景编辑器上栏选项创建子项，也可以用代码创建

```python
$MenuButtom.get_popup().add_item("Open file") #增加子项 “Open file”
$MenuButtom.get_popup().connect() #增加事件
$MenuButtom.get_popup().get_item_text(id) #获取子项名称

```
